# בר השגה – מושגי חסידות בהישג יד

תרשים אחד של מושגי החסידות, מאין סוף ועד ימות המשיח: כל מושג במקומו, עם הסבר קצר ומקורות.

**האתר:** https://menucha770.github.io/bar-hasaga/

## מה יש כאן
כל האתר הוא קובץ אחד: `index.html`. הטקסט, העיצוב והקוד נמצאים כולם בתוכו.
שאר הקבצים הם האייקונים ותמונת התצוגה לשיתוף (`og.png`, `favicon*`, `apple-touch-icon.png`).

## איך עורכים
1. פותחים את `index.html` (כאן ב-GitHub: לוחצים על הקובץ ואז על סמל העיפרון).
2. משנים ושומרים (Commit changes).
3. אפשר גם לתת את הקובץ לכל כלי בינה מלאכותית (ChatGPT, Claude, Gemini וכו׳), לבקש שינוי, ולהעלות חזרה את הקובץ המעודכן.

## איך זה מתפרסם
GitHub Pages מגיש את האתר ישירות מהענף `main` של המאגר הזה. כל שינוי שנשמר עולה לאוויר אוטומטית תוך דקה-שתיים.
האתר לא תלוי באף שירות אחר.
